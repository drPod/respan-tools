# Respan Assistant Prompts

These prompts are managed in Respan's Prompt Management and called via the gateway API.

## Architecture

```
User Question
     │
     ▼
┌─────────────────────────────────────────────────┐
│                  AGENT LOOP (max 3)             │
│                                                 │
│  ┌─────────────┐   JSON schema   ┌───────────┐ │
│  │  Prompt 1   │ ──────────────► │ next_state │ │
│  │   Router    │  (non-streaming) │           │ │
│  │             │                  │           │ │
│  │ {{docs_index}} ◄── composed   └─────┬─────┘ │
│  │ {{accumulated_context}}             │        │
│  └─────────────┘                       │        │
│         ▲                              │        │
│         │                         fetch_docs    │
│         │                              │        │
│         │                     Read MDX files    │
│         │                              │        │
│         └──────── loop back ◄──────────┘        │
│                                                 │
│              answer / clarify = break           │
└──────────────────────┬──────────────────────────┘
                       │
                       ▼
              ┌─────────────────┐
              │   Prompt 2:     │
              │   Answerer      │
              │   (streaming)   │
              │                 │
              │ {{docs_content}}│ = accumulated docs + router context
              │ {{user_question}}│
              └─────────────────┘
                       │
                       ▼
                 Stream to user
```

- **Router** loops up to 3 times. Each `fetch_docs` iteration fetches MDX files and feeds them back as `{{accumulated_context}}` on the next iteration.
- **Router** breaks the loop on `answer` or `clarify`, passing control to the Answerer.
- **Answerer** is always the terminal step — streaming response to the user.
- **Docs Index** is composed into the Router via `{{docs_index}}` using Respan's prompt composition (`{ _type: "prompt", prompt_id: "..." }`).

## Prompt 1: Router

**Name**: `assistant-router`
**Prompt ID**: `902088dc72a442bbba92fe3bf1da5c1c`
**Model**: `gpt-4o-mini`
**Streaming**: No
**Response format**: `json_schema` (enforced by API caller, not prompt config)

### System Message

You are a routing agent for the Respan documentation assistant.

Respan is an LLM observability and evaluation platform. It provides:
- **Tracing & Logging**: Capture LLM calls (spans) grouped into traces with metadata, costs, latency
- **Prompt Management**: Version, test, and deploy prompts with variables and model config
- **Datasets & Evaluation**: Build test datasets, run experiments with evaluators (LLM-as-judge, code, similarity)
- **Gateway**: OpenAI-compatible proxy that adds logging, caching, prompt management
- **SDKs**: Python and TypeScript SDKs for tracing, plus OpenAI SDK compatibility via gateway

Your job: Given a user question about Respan, decide what to do next.

Here is the complete documentation index:

{{docs_index}}

### User Message

User question: {{user_question}}

{{accumulated_context}}

Decide the next action:
- **answer**: You have enough context to answer. Use when: (a) the question is broad and general knowledge suffices, OR (b) documentation has already been fetched above and covers the question.
- **fetch_docs**: You need specific documentation pages. Pick 1-5 doc paths from the index. Do NOT re-fetch paths that already appear in the accumulated context above.
- **clarify**: The question is about Respan but too vague. Ask the user to clarify.
- **reject**: The question is NOT about Respan. This is a strict rule — any question unrelated to Respan must be rejected. Put a brief reason in `context`.

### JSON Schema (enforced by caller)

```json
{
  "type": "json_schema",
  "json_schema": {
    "name": "router_decision",
    "strict": true,
    "schema": {
      "type": "object",
      "properties": {
        "next_state": {
          "type": "string",
          "enum": ["answer", "fetch_docs", "clarify", "reject"]
        },
        "doc_paths": {
          "type": "array",
          "items": { "type": "string" },
          "description": "Doc paths to fetch. Required when next_state is fetch_docs."
        },
        "context": {
          "type": "string",
          "description": "Brief context for the answerer about what to focus on."
        }
      },
      "required": ["next_state", "doc_paths", "context"],
      "additionalProperties": false
    }
  }
}
```

## API Call Details

### Router call (non-streaming, JSON schema, called in loop)

```typescript
// POST https://api.respan.ai/api/chat/completions
// Called up to 3 times. Each fetch_docs iteration adds to accumulated_context.
{
  model: "gpt-4o-mini",
  messages: [{ role: "user", content: userQuestion }],
  stream: false,
  prompt: {
    prompt_id: "902088dc72a442bbba92fe3bf1da5c1c",
    variables: {
      docs_index: {
        _type: "prompt",
        prompt_id: "34d4ffd3913c40a0a51a9eae478ca22b"
      },
      user_question: userQuestion,
      accumulated_context: ""  // empty on first call, grows with fetched docs
    }
  },
  response_format: { /* JSON schema above */ },
  schema_version: 2
}
```

### Answerer call (streaming)

```typescript
// POST https://api.respan.ai/api/chat/completions
{
  model: "gpt-4o-mini",
  messages: conversationHistory,  // full history for multi-turn
  stream: true,
  prompt: {
    prompt_id: "fdb0e5b3c6bc451e89e73d8d827557a4",
    variables: {
      docs_content: answererContext,  // varies by next_state
      user_question: userQuestion
    }
  },
  schema_version: 2
}
```

### Context by `next_state` (after loop completes)

| next_state   | `docs_content` value |
|-------------|---------------------|
| `answer` (no docs fetched) | `"Answer from your general knowledge of Respan. Context: {router.context}"` |
| `answer` (docs fetched) | `"Router context: {router.context}\n\nDocumentation:\n{accumulated docs}"` |
| `fetch_docs` (hit max iterations) | `"Router context: {router.context}\n\nDocumentation:\n{accumulated docs}"` |
| `clarify`   | `"The user's question is unclear. Ask them to clarify. Context: {router.context}"` |
| `reject`    | Skips Answerer entirely. Returns `"Sorry, I can only answer questions about Respan. {router.context}"` as a direct SSE response. |
